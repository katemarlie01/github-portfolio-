### 1. Navigation & Header
* *Sticky Navbar:* Header stays fixed at the top during scrolling for easy section navigation (#about, #goals, #skills, #projects, #achievements, #interests, #education, #contact).
* *Branding:* Soft pink logo badge 🌸 Kate's Portfolio`) with interactive hover states.

### 2. Header / Hero Section
* *Profile Image Container:* Encapsulates the user ID picture with a soft white border and glowing shadow effect.
* *CSS Animations:*
  * Floating keyframe animation (@keyframes float) applied to the profile picture.
  * Rotating sparkle badge (@keyframes spin) positioned near the profile image.
* *Call to Action (CTA):* Pink button (Get In Touch 💌) directing users to the contact card.

### 3. Styling & Aesthetics
* *Color Palette:* Feminine soft pastel pink palette (#fffafc, #fce7f3, #fbcfe8, #f472b6, #db2777, #831843).
* *Typography:* Clean Google Font integration (*Poppins*) with multiple font weights (300, 400, 500, 600, 700).
* *Icons:* FontAwesome vector icons integrated into skill badges (HTML5, CSS3, C++, GitHub, Problem Solving) and contact channels.

### 4. Interactive Components & Layout
* *Hover Card Effects:* Section cards smooth-lift (transform: translateY(-5px)) and deepen shadows on cursor hover.
* *Interactive Skill Badges:* Grid layout cards that rotate slightly (rotate(-2deg)) and change color when hovered.
* *Custom List Bullet Styling:* Cherry blossom emoji bullet points 🌸`) for goals and achievements lists.
* *Interest Pills:* Styled tags for quick visual categorization of personal passions.

### 5. Responsive Web Design
* *Flexbox & CSS Grid:* Dynamic card grids adjusting automatically across screen sizes.
* *Mobile Viewport Optimization:* Uses @media (max-width: 768px) queries to re-align navigation and scale text sizes for mobile screens without horizontal scrollbars.
