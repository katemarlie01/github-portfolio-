---

## 🛠️ Features & Technical Implementation

### 1. HTML5 Structure & Accessibility
* *Semantic Elements:* Utilizes semantic HTML tags such as <header>, <nav>, <main>, <section>, and <footer> for better structural organization and readability.
* *Accessibility:* Includes descriptive alt tags for images, clear text contrast, logical heading hierarchy (<h1> to <h3>), and keyboard-accessible links.

### 2. CSS3 Styling & Layout
* *Typography:* Uses Google Fonts (*Poppins*) for modern, clean text rendering.
* *Layout Techniques:* Utilizes Flexbox and CSS Grid for structured section arrangements.
* *Interactive Elements:* Features custom CSS animations, hover effects, floating image keyframes, and soft shadow highlights.

### 3. Responsive Design
* Optimized for both *Desktop/Laptop* and *Mobile* viewports using CSS @media queries to ensure no horizontal scroll issues.
