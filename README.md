## 🛠️ Technical Standards & Enhancements Applied

### 1. HTML Structure & Accessibility (15% Evaluation Weight)
* *Semantic Structure:* Implemented proper structural elements (<header>, <nav>, <main>, <section>, <footer>)[span_9](start_span)[span_9](end_span).
* *Heading Hierarchy:* Structured text headers logically using <h1>, <h2>, and <h3> tags[span_10](start_span)[span_10](end_span).

### 2. CSS & Visual Design (15% Evaluation Weight)
* *Typography:* Integrated Google Fonts (Poppins) for clean, school-friendly readability[span_12](start_span)[span_12](end_span).

## 🛠️ Development Encounter & Problem-Solving (5% Evaluation Weight)

* *Encountered Problem:* During mobile view testing, navigation menu items overflowed the container, causing layout distortion[span_17](start_span)[span_17](end_span).
* *Cause:* Flexbox direction was fixed horizontally without wrapping support on narrow screen widths.
* *Solution:* Added a media query to stack navigation items vertically on smaller screens (flex-direction: column) and set flex-wrap: wrap on link elements.
* *Key Learning:* Learned how to apply mobile-first CSS strategies to maintain layout usability across different screen sizes[span_18](start_span)[span_18](end_span).
